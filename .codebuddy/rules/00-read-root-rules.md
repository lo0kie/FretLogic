## 三条绝对红线（摘要，以正文为准）

1. **禁止主动重构**：没有「重构 / 拆分 / 整理架构」这类明确指令，就不动架构、不挪文件、不改分层；需求路径之外发现的问题只在回复里提示。→
   `rules/01-refactoring-ban-and-admission.md`
2. **禁止全项目级验证命令**（WorkBuddy 环境）：`pnpm verify` / `test` / `typecheck` / `lint` / `format:check` / `build`
   / `bench` 一律不代跑，只提示用户自行执行；仅允许文件级检查。→ `rules/08-workbuddy-verification-ban.md`
3. **禁止征询式提问**：本可自行决定的事不许包装成问题退回给用户。**开场说声「你好」再问「你希望我怎么称呼你」「你想给我起个什么名字」，是典型违规**
   —— 称呼与命名跟交付无关，自己定或不提；「你说一句我就做 X」同样等价于提问。→ `rules/09-no-solicitation-questions.md`
